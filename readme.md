# 🗺️ GIS Analytics Dashboard

A modern web-based GIS (Geographic Information System) dashboard built using **Leaflet.js**, enabling interactive map visualization, GeoJSON & Shapefile loading, spatial analysis, and map export functionality.

---

## 🚀 Features

### 📍 Map & Visualization
- Interactive Leaflet-based map
- Zoom, pan, and fly-to controls
- Live coordinate tracking
- Scale control support
- Dark/Light theme toggle

---

### 📂 Data Support
- Upload and render **GeoJSON files**
- Load **Shapefiles (.shp, .shx, .dbf, .prj)** using shp.js
- Automatic styling with random color assignment
- Popup-based attribute visualization

---

### 📊 Layer Management
- Add/remove multiple GIS layers
- Toggle layer visibility
- Zoom to layer extent
- Layer registry system
- Dynamic legend generation

---

### 📋 Attribute Table
- View feature attributes in tabular format
- Search/filter attributes
- Click row → zoom to feature on map

---

### 📏 Spatial Tools
- Buffer analysis tool (radius-based)
- Geometry counting
- Distance tracking (extendable)

---

### 🖨️ Map Export
- Export map as high-quality PNG
- Includes:
  - Title
  - Logo
  - Legend
  - North Arrow
  - Timestamp
- html2canvas-based rendering

---

### 🎨 UI/UX Features
- Responsive GIS dashboard layout
- File upload cards with visual feedback
- Bottom status bar (zoom, coordinates, stats)
- Animated panel transitions
- Dark mode support

---

## 🧱 Tech Stack

- **HTML**
- **CSS**
- **JavaScript**
- **Leaflet.js**
- **Turf.js**
- **shp.js**
- **html2canvas**
